# Ann Equipment for TypeScript

Equipment for producing TypeScript artifacts with [Ann][1].

## Installation

Installation is done using the standard `npm install --include=dev`, but a generic interface is offered to standardize 
accross different supported language environments. 

```shell
$ bin/install.sh
```

## Testing

Testing is done using `vitest`, but a generic interface is offered to standardize accross different supported language 
environments.

```shell
$ bin/test.sh
```

[1]: https://tryitwithann.com/
